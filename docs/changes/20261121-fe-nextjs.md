# Thêm frontend Next.js (`fe/`) liên kết với BE

## Mục tiêu
Nhánh `konan` chưa có FE (FE cũ chỉ còn ở `main`, viết cho API đã bỏ). Dựng khung FE mới bằng Next.js và nối được với BE.

## Đã làm
- `fe/`: Next.js 16 (App Router, TypeScript, ESLint, không Tailwind, `src/`), tạo bằng `create-next-app`. Giữ `cacheComponents` và
  `partialPrefetching` do template bật; bỏ font Google (không phụ thuộc mạng ngoài) và các file mẫu.
- `fe/next.config.ts`: `rewrites` `/api/:path*` → `${BE_URL}/api/:path*` (`BE_URL` mặc định `http://localhost:8000`). Trình duyệt gọi cùng origin, không cần CORS.
- `fe/src/lib/api.ts` (`getFromBackend`: fetch không cache, timeout 5 giây, BE tắt thì trả lỗi chứ không làm trang vỡ).
- Trang chủ `fe/src/app/page.tsx`: `ServerStatus` (Server Component trong `<Suspense>`, gọi `/api/health/readiness` và `/api/agent/health`)
  và `ClientPing` (trình duyệt gọi `/api/health` qua proxy).
- `scripts/start.sh` bật thêm FE (xem `20261121-scripts-start.md`); `Makefile`: `fe-run`, `fe-lint`, `make install` có `npm ci`; `.env.example`: `NEXT_PORT`.
- `CLAUDE.md` và `fe/README.md` cập nhật.

## Cách kiểm tra
- `cd fe && npm run lint && npx tsc --noEmit && npm run build` đều qua.
- `NEXT_PORT=3100 scripts/start.sh`: trang `http://localhost:3100` hiện Backend, database và Agent đều `UP`;
  `curl localhost:3100/api/health` và `/api/agent/health` trả dữ liệu của BE.

## Chưa kiểm tra / còn lưu ý
- Chưa mở trang bằng trình duyệt thật (kiểm bằng `curl` nội dung HTML và proxy); nút "Gọi thử" của `ClientPing` chưa bấm thật.
- Chưa có màn hình nghiệp vụ, đăng nhập, thiết kế giao diện, test FE; chưa thêm job FE vào CI.
- `fe/AGENTS.md` do Next sinh ra (cảnh báo phiên bản Next khác kiến thức cũ, đọc `node_modules/next/dist/docs/`); giữ lại.
- Cổng 3000 trên máy dev đang bị FE của DDDTN chiếm; dùng `NEXT_PORT` để đổi.
