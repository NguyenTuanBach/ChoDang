# Nhóm 3 — xác minh OIDC id_token

Đã bổ sung xác minh `id_token` khi IdP trả token trong authorization-code flow:

- Chỉ chấp nhận RS256/RS384/RS512.
- Kiểm tra chữ ký bằng khóa RSA lấy từ JWKS của IdP.
- Kiểm tra `iss`, `aud`, `exp` và `nonce`.
- Giữ fallback tương thích với IdP chỉ trả `access_token` trong môi trường test.

Rate limit và danh sách JWT bị thu hồi hiện vẫn là in-memory; triển khai nhiều worker cần chuyển sang Redis hoặc database dùng chung.
